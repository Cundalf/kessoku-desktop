# Evaluación de componentes — 12 noviembre 2026

Las versiones concretas de esta máquina son Debian 13.7; plasma-workspace 6.3.6-2; kwin-wayland 6.3.6-1; Konsole 25.04.2; KF CoreAddons 6.13.0; Qt 6.8.2. Los widgets y Breeze provienen de Debian. Se agregó JetBrains Mono 2.304+ds-5 mediante extracción del .deb oficial APT para el usuario, sin instalar el paquete: el SHA-256 se comprueba en install.sh. Se desactiva retirando la referencia del perfil o restaurando konsolerc; los archivos de fuente quedan instalados para no romper usos posteriores.

* [Catppuccin KDE](https://github.com/catppuccin/kde/releases): v0.4.0 es la última publicación listada; el proyecto tiene versión para Plasma 6 pero su instalador modifica kwinrc y no se inspeccionó integralmente. No se ejecutó; se creó un esquema local basado en Breeze con la paleta solicitada.
* [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme/releases): última publicación listada 20260801, Debian ofrece 20250501-1 y requiere hicolor-icon-theme. Se conserva Breeze instalado; el paquete Papirus de Debian declara 187357 KiB instalados. El proyecto advierte limitaciones de recoloreado en Plasma 6. No se instaló.
* [Kvantum](https://github.com/tsujan/Kvantum/releases): última publicación listada 1.1.8; motor Qt con actividad reciente. No es necesario para los widgets nativos, añade otra capa de estilo y su comportamiento concreto con esta sesión 6.3 no se ha probado. No se instaló.
* [Panel Colorizer](https://github.com/luisbocanegra/plasma-panel-colorizer/releases): última publicación listada 8.0.0; proyecto activo. La función de blur personalizado requiere plugin C++ y la versión 8 exige recompilar ese plugin. Su compatibilidad completa con Debian 6.3 y sus dependencias no se han verificado; no se instaló. La opacidad adaptativa es la alternativa nativa.
* [Kara](https://github.com/dhruv8sh/kara): paginador adicional, con cambios entre versiones de Plasma y dependencia histórica de una API privada. La última publicación listada es v1.1.0; desde v1.0.0 exige compilar un plugin C++ con CMake, compilador y dependencias Qt/KF de desarrollo. No se verificó esta publicación en Plasma 6.3 ni se instaló; se usa el paginador nativo. Fuente: https://github.com/dhruv8sh/kara/releases . Referencia de la ruptura en versiones posteriores: https://github.com/dhruv8sh/kara/issues/41 .
* [Lightly](https://github.com/Luwx/Lightly): archivado y sin mantenimiento; no se instaló. [Darkly](https://github.com/Bali10050/Darkly) es un sucesor, pero requiere componentes de estilo/decoración nativos y no se verificó contra la ABI de Debian 6.3; se conserva Breeze.
* Multimedia y monitores: son widgets de Plasma 6.3.6 ya instalados. Una prueba local con VLC 3.0.24 mostró carátula, canción, artista, álbum y controles; D-Bus confirmó reproducción y pausa. No se comprobó el clic sobre cada botón del widget. No se instaló código QML externo.
* KWin: se forzaron blur, scale y slidingpopups con kwriteconfig6 y se aplicaron por D-Bus. Overview está cargado, Desktop Grid no figura como efecto independiente compatible. No se instalaron efectos externos. La restauración devuelve kwinrc respaldado.

Los proyectos no instalados no requieren desinstalación. Sus versiones y compatibilidad se revisaron solo para decidir no instalarlos; no se realizó auditoría de seguridad del código ni se afirma ausencia de vulnerabilidades. No se agregaron repositorios, paquetes APT, Starship ni scripts de shell automáticos.
