# Kessoku Desktop — diseño y alcance

La composición usa superficies índigo #1e1e2e y #11111b, texto #cdd6f4 y acentos rosa #f5c2e7, violeta #cba6f7 y azul #89b4fa. El fondo es una ilustración original generada para este proyecto, con escenario musical nocturno y espacio libre para widgets; no reproduce personajes ni imágenes de terceros. El original mide 1672 × 941; la versión aplicada se reescaló con Upscayl/High Fidelity a 3840 × 2160 y Plasma la reduce para el monitor de 1920 × 1080.

El panel superior flotante mantiene lanzador, paginador, bandeja y reloj. El reproductor y los medidores discretos CPU/RAM están en el escritorio, según la preferencia del usuario. El separador expansible conserva la alineación de la bandeja a la derecha. El dock inferior utiliza el gestor de tareas nativo con Dolphin, Konsole, navegador predeterminado, VS Code, Steam y Spotify; se oculta al superponer ventanas. El reloj y la tarjeta multimedia de escritorio están a la izquierda. El reloj superior sigue disponible por requisito funcional y el reloj de escritorio cumple una función visual.

Los paneles usan el modo translúcido oficial de Breeze. Se aplica mediante `reload-plasma.sh`, con plasmashell detenido, porque el setter de scripting de Plasma 6.3.6 no actualiza opacityMode. No se modifican binarios ni se parchea KWin. KWin tiene blur, escala y ventanas emergentes deslizantes cargados; Overview está disponible. Desktop Grid no aparece como efecto independiente soportado; se conserva Overview. Scale anima apertura y cierre; Magic Lamp de 400 ms anima minimización y restauración; Wobbly en nivel suave solo al mover. Squash, Glide y Fade quedan desactivados para evitar competencia. El factor global de duración es 0,75. No se reemplazó la decoración Breeze ni se aplicaron parches KWin.

Konsole usa el perfil Kessoku para nuevas ventanas: JetBrains Mono y esquema de colores con opacidad 0,90 y blur solicitado. Una terminal anterior puede conservar su perfil. `fastfetch --config ~/Projects/kessoku-desktop/configs/fastfetch/config.jsonc` muestra un resumen acorde sin tocar archivos de shell ni ejecutarse automáticamente.

Se comprobó visualmente el blur y la transparencia de Konsole sobre el fondo en una ventana de prueba; su captura aislada también contiene alfa 230/255, correspondiente a opacidad 0,90. El dock desapareció al maximizar una ventana y volvió al terminar la prueba.
